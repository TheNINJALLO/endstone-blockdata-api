# Minecraft 1.26.60 native target

Linux x86-64 native release for Minecraft **1.26.60**, BDS **1.26.60.6**, and Endstone **0.11.15**, with matching CPython **3.14** command wheels.

Endstone package metadata accepts **>=0.11.11** with no upper bound. Native hooks require the verified BDS 1.26.60.6 / Endstone 0.11.15 binary pair; later private runtimes need separate qualification.

Linux native qualification and binary identities are recorded in `compatibility/bds-1.26.60.json`. Windows server identity is retained for provenance; this release qualifies Linux only.

Network protocol is **2225**. Qualification uses the default `enable-script=true`; see `compatibility/native-qualification.json` for the executed scope.
